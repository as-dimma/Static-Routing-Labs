# Static Routing

A collection of hands-on networking labs documenting my journey towards understanding and mastering Static Routing using Cisco Packet Tracer.

About This Repository

This repository contains practical exercises designed to strengthen my understanding of static routing, IP addressing, subnetting, and how routers forward packets between different networks.

Rather than documenting only successful configurations, I also share the challenges I encounter, troubleshooting processes, mistakes, and lessons learned throughout each lab.

Repository Structure

Each lab is organised into its own directory containing:

- README.md: Lab documentation, implementation process, challenges, troubleshooting, and key takeaways.
- Context: The scenario, requirements, and objectives of the lab.
- Packet Tracer File: The ".pkt" project file.
- Screenshots: Visual documentation of configurations and verification.
- Topology: A visual representation of the network design.

Topics Covered

- Static route configuration
- Next-hop addressing
- Routing tables and route selection
- Directly connected and remote networks
- Default static routes
- Floating static routes
- Inter-network communication
- Routing troubleshooting and verification

Topics will be added as I progress.

Tools and Technologies

- Cisco Packet Tracer
- Cisco routers and switches
- Cisco IOS CLI
- IPv4 addressing and subnetting
- Markdown and GitHub

Learning Approach

Each lab documents:

- The problem or scenario being addressed.
- The objectives and expected outcomes.
- Network design and implementation.
- IP addressing and subnet allocation.
- Static route configuration.
- Connectivity testing and verification.
- Challenges and troubleshooting.
- Key lessons learned.

Progress

This repository is a work in progress. Labs will be added as I explore, practise, and deepen my understanding of static routing and its implementation in real-world networking environments.
